# `zagent setup`

Initialize `~/.zagent/zagent.json` and the agent workspace.

Related:
- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
zagent setup
zagent setup --workspace ~/clawd
```

To run the wizard via setup:

```bash
zagent setup --wizard
```
